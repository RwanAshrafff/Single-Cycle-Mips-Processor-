# 🧠 Single Cycle MIPS Processor

A cycle-accurate implementation of a **Single-Cycle MIPS Processor** designed in hardware description language (HDL).  
This project demonstrates the architecture, datapath, and control logic of a basic MIPS CPU that executes instructions in a single clock cycle.

---

## 🚀 About

This project models a simple **MIPS CPU** capable of executing arithmetic, control, memory, and branching instructions within one clock cycle.  
It includes:

- Instruction Fetch
- Instruction Decode
- Execute
- Memory Access
- Write Back

The CPU design follows the classic *Single-Cycle MIPS architecture* used in computer organization courses.

---

## 🧱 Features

✔ Supports basic MIPS instructions  
✔ Implements full datapath with ALU, registers & control units  
✔ Includes instruction and data memory  
✔ Demonstrates single-cycle execution for all instructions  
✔ Easy to simulate and test using Verilog or VHDL simulators
